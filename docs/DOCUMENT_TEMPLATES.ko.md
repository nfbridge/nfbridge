# 출력 언어와 개인 양식

[English](DOCUMENT_TEMPLATES.md)

롤 목록 아래 **문서 양식**에서 **화면 언어 따르기 / 한국어 / English**를 선택하세요. HTML·읽기용 CSV·기본 롤로그·출력 안내문에 적용합니다. JSON 키와 ExifTool CSV 태그는 다른 프로그램에서 읽을 수 있도록 유지합니다. 필름 이름과 사용자 메모는 번역하지 않습니다.

개인 Markdown 양식은 다음 순서로 사용합니다.

1. **예제 양식 저장**을 누르고 저장된 `.md`를 텍스트/Markdown 편집기로 엽니다.
2. 자신의 제목과 빈 메모 칸은 그대로 두고, 필요한 곳에 자리표시자를 배치합니다.
3. **개인 Markdown 양식 → 양식 파일 선택 → 미리보기 → 적용**을 누릅니다.
4. **저장**에서 촬영일지 Markdown을 선택하면 롤로그 `.md`에 개인 양식을 적용합니다. HTML과 기계용 파일 구조는 바꾸지 않습니다.

최소 예제:

```markdown
{{frontmatter}}

# {{roll_id}}

필름: {{film}} · EI: {{iso}}

## 내 메모

- 피사체:
- 의도:
- 리뷰:

{{frames_table}}
```

`{{frontmatter}}`는 `---` 경계까지 포함한 전체 YAML을, `{{frames_table}}`은 선택한 문서 언어의 프레임 표를 넣습니다. `{{frame_sections}}`는 컷마다 별도 절을 넣습니다. 개인 양식에 직접 쓴 제목은 원문 그대로 유지합니다.

나머지 항목: `roll_id`, `camera`, `film`, `iso`, `process`, `lab`, `lenses`, `frame_count`, `roll_number`, `record_mode`, `date`, `date_source`, `shooting_date`, `imported`, `film_yaml`, `roll_id_yaml`. 이름을 이중 중괄호로 감싸세요. YAML 필드를 직접 만들 때는 `_yaml` 항목을 추가 따옴표 없이 쓰고, 일반 문장 값은 Markdown용으로 처리합니다. 전체 `frontmatter`를 쓰는 것이 가장 간단합니다.

`shooting_date`는 명시 입력하지 않으면 비웁니다. `date`는 기존 롤로그 규칙대로 입력 날짜 또는 가져온 날짜이며 `date_source`로 구분합니다. F100에 촬영 날짜는 없습니다. Simple에 없는 값은 `-`이고 사람이 쓰는 관찰 칸은 비웁니다.

양식은 UTF-8 Markdown, 최대 256 KB입니다. 위 항목의 치환만 지원하며 수식 실행·반복문·외부 파일 포함·셸/Python 실행은 하지 않습니다. 모르는 항목이나 잘못 닫힌 괄호는 출력 파일 생성 전에 알려줍니다. 채운 값을 다시 템플릿으로 해석하지 않습니다.

선택한 파일 경로는 앱의 로컬 설정에만 기억합니다. 개인 양식을 앱이나 공개 패키지에 복사하지 않습니다. 양식을 수정하면 다음 미리보기/내보내기에서 다시 읽습니다. 기존 출력물과 볼트의 메모는 덮어쓰지 않고 새 출력 폴더를 사용합니다. 양식 변경은 문서 편집으로 끝납니다. 임의 Word/HTML 양식과 프레임 표 열의 자유 정의는 이번 버전 범위 밖입니다.

견본은 사용 허락을 받은 빈 롤로그 구조입니다. 기본 정보·목적·촬영 중 메모·스캔 후 리뷰·프레임 표를 담고, 개인 사진·촬영 기록·메모는 포함하지 않습니다. 선택한 문서 언어로 견본을 저장하고 제목과 빈 칸을 고친 뒤 개인 양식으로 선택하면 됩니다. 프로그램 코드를 수정할 필요는 없습니다.
