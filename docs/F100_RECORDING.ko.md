# F100 기록의 범위와 설정 조건

촬영정보는 필름 장전 후 기록됩니다. 출고 기본값은 기록 꺼짐·메모리 가득 찰 때 오래된 기록 덮어쓰기입니다. 현재 설정은 카메라에서 읽어 확인해야 합니다.

- 기록 설정을 바꾸려면 저장 기록이 없어야 하고 필름 카운터가 E여야 합니다. 앱은 필름 유무를 읽을 수 없어 NP 직전에 사용자의 직접 확인을 묻습니다. 메모리 삭제만으로 E가 되지는 않습니다.
- 변경 설정은 다음 필름을 장전해 첫 프레임으로 진행하면 적용됩니다. 설정 저장 확인은 실제 촬영 데이터가 생겼다는 확인과 다릅니다.
- 저장된 감도는 마지막 노출 컷의 감도입니다. 중간에 감도를 바꾸면 이전 감도는 남지 않습니다. 표의 ‘롤 마지막 감도’와 롤로그 rating_ei는 이 값이며 전 컷 감도를 보증하지 않습니다.
- 이번 공개 앱은 스캔 사진에 ISO를 쓰지 않습니다. 향후 스캔 작업에서는 선택한 롤의 감도를 바꾸지 않았다고 확인한 경우에만 ISO를 쓸 수 있도록 설계했습니다. 출력 CSV도 기본적으로 ISO가 비어 있습니다.
- 다중노출 값은 첫 노출만 기록합니다. 첫 노출 뒤 취소해도 다중노출 표시가 남을 수 있어 실제 완료 횟수는 알 수 없습니다.
- Stop shooting에서 FUL로 멈춘 뒤 전원을 껐다 켜면 경고가 사라지고 기록 없이 촬영을 계속할 수 있습니다. 기록을 재개하려면 저장 데이터를 확보한 뒤 메모리 공간이 필요합니다.
- 자동 덮어쓰기는 새 롤 하나를 저장하면서 과거 여러 롤, 경우에 따라 두 롤보다 많은 기록을 지울 수 있습니다.
- 촬영 중간에도 가져올 수 있습니다. 롤로그의 기본 status는 imported이며 촬영 완료 여부를 뜻하지 않습니다. 촬영 완료를 확인한 사용자가 shot으로 바꿀 수 있습니다.

현재 USB 구성은 PL2303·macOS 내장 드라이버로 검증한 비공식 호환 구성입니다. Nikon 매뉴얼의 MC-31/MC-33·PC 직렬 포트 및 전원 OFF 연결 절차와 다릅니다. 공식 지원 구성이나 전기적 적합성 인증을 뜻하지 않습니다.
