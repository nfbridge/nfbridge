# Neo Film Bridge

**Nikon F100에 저장된 촬영정보를 Mac에서 보고 파일로 보관하는 도구입니다.**

F100은 기록 기능을 켜 두면 컷마다 셔터 속도와 조리개 등을 저장합니다. 이 도구는 그 기록을 가져와 표로 보여 주고 파일로 남깁니다. 기록 기능을 켜기 전에 찍은 사진의 정보는 되살릴 수 없습니다.

[English](README.en.md) · [자세한 사용법](docs/GETTING_STARTED.ko.md) · [이번 버전 변경 사항](RELEASE_NOTES.md)

소스 코드는 이 저장소에 있으며, Apple Silicon Mac용 실행 앱 ZIP은 [Releases](https://github.com/nfbridge/nfbridge/releases)에서 받을 수 있습니다. 압축을 푼 뒤 `START_HERE.md`를 먼저 읽어 주세요.


**이번 공개본은 스캔 사진에 촬영정보를 쓰지 않습니다.** 스캔 버튼과 화면은 제외했으며 ExifTool도 동봉하지 않습니다. 출력되는 ExifTool용 CSV는 향후 작업용 파일일 뿐, 사진을 자동으로 수정하지 않습니다.

버튼에 마우스를 잠시 올리면 짧은 설명이 뜹니다. **저장한 촬영기록 열기**는 이전에 저장한 `shooting-data.json`을 다시 보는 기능입니다. **문서 양식**에서는 출력 언어와 Markdown 촬영일지의 모양을 고릅니다. 처음에는 기본 양식을 그대로 쓰세요.

## 처음 여는 방법

**앱 ZIP을 받았다면** 압축을 풀고 `Neo Film Bridge.app`을 여세요. 응용 프로그램 폴더로 옮겨도 됩니다. `.app` 없이 소스 파일만 있다면 개발자용 ZIP을 받은 것입니다.

믿을 수 있는 곳에서 받은 앱인데 Mac이 실행을 막으면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택하고 안내를 따르세요. Apple의 공증을 받지 않은 앱이라 경고가 나올 수 있습니다. 회사·학교에서 관리하는 Mac은 실행을 허용하지 않을 수도 있습니다. [Apple의 설명](https://support.apple.com/en-us/102445)

**English / 한국어** 버튼으로 언어를 바꿀 수 있습니다. 다음에 열 때도 선택을 기억합니다. 파일을 고르는 창은 Mac의 언어 설정을 따릅니다.

## 어떤 케이블이 필요한가요?

**F100용 10핀 데이터 케이블**이 필요합니다. 셔터를 누르는 용도의 릴리즈 케이블과는 다릅니다.

시험한 구성은 Prolific PL2303을 사용하는 케이블과 macOS 내장 드라이버입니다. **이 앱은 USB 케이블 드라이버를 제공하지 않습니다.** 시험한 구성에서는 별도 드라이버를 설치하지 않았습니다. 다른 케이블에 드라이버가 필요하다면 해당 케이블 제조사의 macOS용 드라이버와 지원 버전을 사용자가 확인해 준비해야 합니다. `Nikon F100 10-pin data cable PL2303`으로 찾아볼 수 있지만, 구매 전 판매자에게 **F100 촬영정보 전송용인지** 확인하세요. 같은 칩을 썼다는 이유만으로 모든 케이블이 맞는 것은 아닙니다. Nikon 공식 케이블과 PC 직렬 포트를 사용하는 옛 매뉴얼의 구성과도 다릅니다.

## 카메라 연결과 가져오기

**가져오기**를 누르고 같은 카메라에 사용할 보관함 이름을 입력하세요. 처음 한 번은 안내에 따라 케이블을 분리하고 USB 쪽부터 연결해 확인합니다. 이후에는 등록한 케이블과 현재 연결이 같은지 앱이 확인합니다. Windows VM이나 다른 카메라 연결 프로그램은 종료해 주세요.

가져오기가 끝나면 롤 목록과 저장 위치가 나옵니다. 같은 기록을 다시 가져와도 보관함에 중복으로 쌓지 않으며, 촬영 중 컷이 늘어나면 이전 기록도 남깁니다.

**기록 설정**은 현재 설정을 먼저 읽습니다. 변경할 설정을 고르면 별도 확인을 받고, **카메라 촬영기록 삭제…**는 먼저 기록을 Mac에 보관하고 확인한 뒤, 최종 삭제 여부를 다시 묻습니다. 삭제 뒤 설정을 바꾸려면 다시 선택하세요.

## 기록을 가져와서 무엇을 할 수 있나요?

저장 버튼을 누르면 아래 다섯 가지 중 필요한 파일만 골라 저장할 수 있습니다. 처음에는 **HTML, 촬영일지, 원본 데이터 보관**만 선택해도 충분합니다. 보는 용도라면 HTML, 표를 편집하려면 CSV부터 열면 됩니다.

| 파일 종류 | 어디에 쓰나요? |
|---|---|
| HTML | Safari 같은 브라우저에서 보는 촬영정보 표입니다. |
| 촬영일지 Markdown | 글과 표로 된 롤별 촬영일지입니다. 텍스트 편집기나 Obsidian 같은 메모 앱에서 편집할 수 있습니다. |
| JSON (원본 데이터 보관) | 앱이 읽은 원본 값과 해석한 값을 그대로 보관하는 기록 파일입니다. 나중에 앱에서 다시 열 때 쓰며, 직접 읽거나 고칠 필요는 없습니다. |
| 일반 CSV | Numbers·Excel 같은 스프레드시트에서 여는 표입니다. |
| EXIF 작업용 CSV | 촬영정보를 스캔 파일에 붙일 때 쓰는 작업용 표입니다. 일반 CSV와 다릅니다. 파일과 컷을 맞추기 전에는 그대로 실행하지 마세요. |

가져오기를 시작할 때 저장 위치와 새 폴더 이름을 고릅니다. 보관함 이름을 기본값으로 제안하며 카메라 내부 기록 번호는 폴더 이름에 붙이지 않습니다. 같은 이름이 이미 있으면 다른 이름을 선택해야 합니다. 다음 저장에서는 마지막으로 사용한 위치를 제안합니다. 앱 내부의 통신 기록은 별도로 보관합니다.

HTML 보고서 제목은 이때 고른 폴더 이름입니다. 영문 출력의 긴 열 제목은 줄바꿈됩니다. 창이 좁으면 표를 가로로 스크롤하고, Safari 화면을 축소하면 더 많은 열을 한꺼번에 볼 수 있습니다.

내보내기 폴더에는 선택한 파일 외에 앱 내부 확인용 숨김 파일이 하나 생깁니다. EXIF 작업용 CSV를 고르면 대응표와 사용 안내 파일도 함께 생깁니다. 앱의 보관함은 `~/Library/Application Support/Neo Film Bridge/`에 있습니다.

**문서 양식**에서 한글·영문 출력이나 개인 양식을 고를 수 있습니다. [내 양식 쓰는 법](docs/DOCUMENT_TEMPLATES.ko.md)

## Simple과 Detailed는 무엇이 다른가요?

**Simple은 기본 촬영값만 남겨 더 많이 저장하고, Detailed는 촬영 상황을 더 자세히 남깁니다.**

| 저장하는 정보 | Simple | Detailed |
|---|---|---|
| 컷 번호·셔터 속도·조리개·촬영 초점거리 | 저장 | 저장 |
| 플래시 사용·다중노출 표시 | 저장 | 저장 |
| 롤 번호·롤 마지막 ISO 감도 | 저장 | 저장 |
| 렌즈의 줌 범위·양 끝 초점거리의 최대 개방 조리개 | 저장 안 함 | 저장 |
| P/S/A/M 촬영 모드·측광 방식 | 저장 안 함 | 저장 |
| 노출보정·플래시 보정·수동 노출계 편차·후막 동조 구분 | 저장 안 함 | 저장 |

Simple로 찍은 뒤에는 기록되지 않은 항목을 나중에 Detailed로 되살릴 수 없습니다. **기본 촬영값만 보관하려면 Simple, 촬영 설정을 자세히 되짚어 보려면 Detailed가 맞습니다.**

| 모드 | 저장할 수 있는 컷 수 | 36컷 필름으로 환산 | 근거 |
|---|---|---|---|
| Simple | **약 2,830컷 예상** | **약 78.6롤** | 실측한 기록 크기로 계산한 예상치. 가득 채우는 시험은 하지 않았습니다. |
| Detailed | **1,103컷 저장 확인** | **약 30.6롤** — 30롤 + 23컷 분량 | 한 번의 실제 메모리 채우기 시험 결과입니다. |

Simple 예상치는 두 모드가 같은 메모리 공간을 쓰고 36컷씩 기록한다고 가정한 계산입니다. 실제 용량은 롤 길이와 카메라의 메모리 관리 방식에 따라 달라질 수 있습니다. Detailed도 36컷 필름으로 다시 채워 본 결과가 아니라, 실측 컷 수를 나눈 환산입니다. [계산 근거](docs/CAPACITY.md)

## 사용 전에 알아둘 점

**설정을 바꿀 때:** 카메라에 저장된 기록이 없어야 하고, 필름 카운터가 **E**여야 합니다. 앱은 카운터를 읽을 수 없어서 사용자가 직접 확인하도록 묻습니다. 확인 뒤 카메라 상태를 다시 읽고, 그대로일 때만 설정을 바꿉니다. 바뀐 설정은 **다음 필름을 넣어 첫 컷으로 진행하면 적용**됩니다.

**ISO 감도:** 카메라는 롤의 마지막 촬영 감도만 남깁니다. 중간에 감도를 바꿨다면 앞선 컷의 감도는 알 수 없습니다. 표에도 ‘롤 마지막 감도’로 표시합니다.

**다중노출:** 첫 번째 노출의 설정만 남습니다. 여러 번 노출한 전체 시간이나 실제 노출 횟수는 알 수 없습니다. Bulb의 실제 시간처럼 알 수 없는 값도 임의로 채우지 않습니다.

**기록 삭제와 메모리:** 가져오기만으로 카메라 기록이 지워지지는 않습니다. 삭제 전에는 Mac에 기록을 저장하고 확인합니다. 다만 카메라에서 자동 덮어쓰기를 선택했다면 새 롤 하나 때문에 예전 여러 롤의 기록이 사라질 수 있습니다. `FUL`로 촬영이 멈춘 뒤 전원을 껐다 켜면 **기록 없이 촬영을 계속할 수 있으니** 주의하세요.


## 삭제 전에 촬영기록을 Mac에 보관합니다

셔터·조리개 같은 촬영정보를 Mac에 저장합니다. **카메라에서 지워도 저장한 기록은 Mac에서 볼 수 있지만, 카메라에 다시 넣을 수는 없습니다.** 사진 이미지나 카메라 전체를 복구하는 파일은 아닙니다.

‘기록 설정 바꾸기’는 앞으로 촬영할 때 무엇을 기록할지 정하는 기능입니다. 이미 찍은 컷의 기록을 고치거나 카메라로 보내는 기능이 아닙니다.

삭제 직전에 새 보관본을 만들고 다시 읽어, 현재 카메라 기록과 같은지 롤별 내용까지 확인합니다. 확인창에는 **“Mac 저장 확인: 5/5롤 · 117컷”**처럼 실제 확인한 수와 보관 폴더가 나옵니다(숫자는 예시). **미리 저장하지 않은 촬영기록은 복구할 수 없습니다.** 확인하지 못한 롤이 있으면 그 수와 번호를 알리고 삭제를 중단합니다. 확인창을 띄운 뒤 파일이 바뀌거나 사라져도 삭제 직전에 다시 검사해 멈춥니다.

## 잘 안 될 때

- **카메라에 연결이 안 돼요:** 전원과 케이블을 확인하고 Windows VM·다른 카메라 연결 프로그램을 종료한 뒤 가져오기를 다시 눌러 보세요. Mac이 케이블 자체를 인식하지 못한다면 제조사에 macOS용 드라이버가 필요한지 확인하세요. 앱에는 드라이버가 없습니다.
- **케이블 확인이 맞지 않아요:** 다른 USB 장치를 원래대로 연결하거나 **도움말 → 케이블 다시 확인**을 사용하세요.
- **가져왔는데 0롤이에요:** 통신 실패와 달리, 현재 카메라 메모리에 기록이 없다는 뜻입니다. 기록 기능이 켜져 있는지 화면 안내를 확인하세요. 기록을 켜기 전 촬영값은 되살릴 수 없습니다.
- **기록 설정을 바꿀 수 없어요:** 카운터 E와 빈 기록 메모리, 두 조건이 모두 필요합니다. 기록을 지워도 카운터가 E로 바뀌지는 않습니다.
- **저장 확인에 실패해 삭제가 멈췄어요:** 안내된 폴더의 촬영기록 파일을 확인하고 다시 저장하세요. 확인하지 못한 상태에서는 카메라 기록을 지우지 않습니다.
- **다른 오류가 났어요:** 화면 안내를 확인하세요. 개발자에게 보여 줄 기록은 `~/Library/Logs/Neo Film Bridge/`에 있습니다.
